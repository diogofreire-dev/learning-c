# learning-c

C exercises from my first year of a CTESP in Cybersecurity at ISTEC.

## Goal
Build a solid foundation in C (pointers and memory) so I can later understand Assembly and, eventually, software security.

## 6-week plan
- [ ] Week 1: basic syntax, loops and functions
- [ ] Week 2: arrays and strings
- [ ] Week 3: pointers
- [ ] Week 4: malloc/free, gdb and memory errors
- [ ] Week 5: C vs Assembly (Compiler Explorer)
- [ ] Week 6: stepping through programs with gdb

## How to compile
gcc -Wall -Wextra -g file.c -o file
./file
